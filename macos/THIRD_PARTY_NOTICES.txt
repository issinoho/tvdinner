This macOS build bundles a libmpv.dylib built by Homebrew's `mpv`
formula:

    https://formulae.brew.sh/formula/mpv

which builds and redistributes binaries of mpv (https://mpv.io),
licensed under the GNU General Public License v2 or later, unless
built with --enable-lgpl, in which case the GNU Lesser General Public
License v2.1 or later applies instead. This notice conservatively
assumes GPL-2.0-or-later, the stricter of the two, since it hasn't been
confirmed which one Homebrew's formula actually configures -- check
`brew info mpv` and the formula source at build time, and correct this
file if it turns out to be built with --enable-lgpl. See:

    https://github.com/mpv-player/mpv/blob/master/LICENSE

for mpv's full license terms, and the Homebrew formula above for the
build recipe used to produce the bundled dylib.

This build also bundles libmpv's own linked dependencies (ffmpeg,
libass, x264, x265, and others pulled in by Homebrew's mpv formula) as
separate files alongside it, rather than leaving them unbundled and
resolved against a Homebrew install that may not exist on the machine
running tvdinner. Each has its own license (several, including x264/
x265, are GPL); this notice doesn't itemize them individually -- run
`brew info mpv` (or `brew deps --tree mpv`) against the same formula
version noted above for the exact list, and treat the aggregate the
same conservative way as libmpv itself, above.
